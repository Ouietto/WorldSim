Asabiya test builds

Work-in-progress versions for comparing one change at a time. The main game is here.

  • Base: the working version these are built on (real rivers, floodplains, tribal frontier, pastoral steppe).
  • Forest clearing: fields are cleared land; standing forest yields only slash-and-burn plots until people clear it.
  • Crops required: farming only arrives with a domesticated crop; before that, only tending wild stands.
  • Transition raids: villages half-way to farming are raided by mobile neighbours and can fall back.
